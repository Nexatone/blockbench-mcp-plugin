# Hytale animation workflow (optional integration)

Inspect supported native animation channels. Use batched animation editing and exposed interpolation values: linear, catmullrom, bezier or step. Do not pass smooth as an interpolation enum.

Use hytale_create_visibility_keyframe and hytale_set_animation_loop for those features. Verify timing, quaternion behavior and loop serialization against the installed plugin instead of assuming a fixed frame rate. Walks coordinate opposite limbs; idle motion uses restrained periodic keys; attacks define preparation, strike and recovery. Preview, validate and verify export/reopen.
